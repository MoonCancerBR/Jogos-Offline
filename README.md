# 🎮 Coleção de Jogos Offline

Este repositório contém uma coleção de jogos simples e offline, perfeitos para passar o tempo em viagens longas ou momentos de tédio. 

🤝 **Sobre o projeto:**
- É um projeto **entre amigos** e **100% sem fins lucrativos**.
- Criado puramente por diversão, curiosidade e aprendizado.
- Grande parte do código e das mecânicas nasce de testes e brincadeiras com IAs generativas (como o Antigravity!).
- Os jogos são desenvolvidos inicialmente em **Python**, com foco em diversão casual e acessibilidade sem necessidade de internet.

🚀 **O que vem por aí (Roadmap):**
- ✨ Melhorias na interface e identidade visual dos jogos.
- ⚙️ Aprimoramentos gerais de jogabilidade.
- 👥 Implementação de modos multiplayer para jogar com a galera.
